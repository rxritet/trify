# Trify для web

Web-оболочка хранится в `web/`, а весь интерфейс и бизнес-логика используются из общей папки `lib/`. Web не имеет отдельной копии приложения.

## Запуск

```bash
flutter pub get
flutter run -d chrome
```

Для запуска через локальный веб-сервер:

```bash
flutter run -d web-server --web-hostname 127.0.0.1 --web-port 51234
```

После запуска откройте `http://127.0.0.1:51234/`.

## Production-сборка

```bash
flutter build web --release
```

Статический сайт появится в `build/web/`. Папка не хранится в репозитории: её следует развёртывать в хостинге как готовый артефакт.

## Особенности

- Google-вход использует Firebase popup;
- локальные данные профиля используют `shared_preferences` браузера;
- данные планировщика Google-пользователя синхронизируются с Firestore;
- поиск мест обращается к Wikimedia REST API, поэтому нужен доступ к сети.
