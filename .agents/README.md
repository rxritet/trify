# Рабочая зона агентов Trify

Эта папка содержит только материалы, нужные агентам при работе с репозиторием. Она отделена от исходного кода, публичной документации и результатов сборки.

## Порядок чтения

1. [PROJECT.md](PROJECT.md) — подтверждённое состояние, ограничения и правила развития.
2. [QUALITY.md](QUALITY.md) — какие проверки запускать и как сообщать результат.
3. Документы из `docs/`, относящиеся к задаче: платформа, архитектура, продукт или безопасность.

## Границы

- Не считать планы из `docs/product/roadmap.md` реализованными функциями.
- Не добавлять в Git ключи, пароли, локальные Android-настройки, кэши или результаты сборок.
- Не изменять чужие незакоммиченные правки без явной необходимости.
- Описывать подтверждённые возможности на русском, а идентификаторы, пути и команды оставлять на английском.

Публичные инструкции для человека, который хочет запустить или изменить проект, находятся в [CONTRIBUTING.md](../CONTRIBUTING.md).
